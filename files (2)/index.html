The Basics: P, NP and NP-Complete

P

P

Problems we can solve quickly (in polynomial time).

Example: sorting a list
NP

NP

Problems where a given answer can be checked quickly.

Example: Sudoku, 3-SAT
NPC

NP-Complete

The hardest problems in NP. Solve one quickly and you can solve all of NP quickly.

Example: CLIQUE
Every problem in P is also in NP. Whether P = NP is still an open question.

Two Conditions for NP-Completeness

In NP+ NP-Hard= NP-Complete
1

Condition 1: It is in NP

A proposed answer (a certificate) can be checked in polynomial time.

CLIQUE: check that the chosen vertices are all connected to each other.
2

Condition 2: It is NP-Hard

Every problem in NP can be reduced to it in polynomial time.

In practice: reduce one known NP-complete problem to it.

How to Prove It Using Reduction

1

Show B is in NP

Show a solution can be verified in polynomial time.

2

Pick a known problem A

Choose a problem A already known to be NP-complete.

3

Build the reduction

Convert any instance of A into an instance of B, in polynomial time.

4

Prove YES = YES

A says YES exactly when B says YES.

Why it works: if B were easy, A would be easy too. But A is hard, so B must be hard.

Example 1: 3-SAT → CLIQUE

  1. 1

    Make vertices. Every literal in every clause becomes a vertex.

  2. 2

    Add edges. Join two vertices if they are in different clauses and are not opposites (x and ¬x).

  3. 3

    Result. The formula is satisfiable exactly when the graph has a clique of size k (k = number of clauses).

(x ∨ y ∨ z) ∧ (¬x ∨ y ∨ ¬z), so k = 2

The y–y edge is a 2-clique: set y = TRUE and both clauses are satisfied.

Example 2: CLIQUE → VERTEX COVER

  1. 1

    Start. Graph G with n vertices; we look for a clique of size k.

  2. 2

    Build G′. The complement: join two vertices exactly when G did not.

  3. 3

    Result. G has a k-clique exactly when G′ has a vertex cover of size n − k.

Why: G′ has no edge inside the clique, so the other n − k vertices touch every edge.

Graph G

Clique {A, B, C}
k = 3

Complement G′

Vertex cover {D}
n − k = 4 − 3 = 1
